# Privacy policy

eng-team is a set of instructions (one skill and six agent definitions) that run inside Claude Code
on your own machine. It contains no code that runs on its own, no servers and no connectors.

- It does not collect, store or send any personal data.
- It does not send any data to the author or to any third party.
- Everything it does happens inside your Claude Code session, under Anthropic's own terms and
  privacy policy. The only files it writes are in your project, including an optional
  `.eng-team/` folder with the task plan, which you can delete at any time.

Questions: open an issue at https://github.com/jacqzlouis-arch/eng-team/issues
